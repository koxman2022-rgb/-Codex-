  • 不自動送出、不儲存、不列印。
  • 不自動寫回 ER_Main。
  • 不把病歷內容傳到外部服務。

掃描label.DetailLi

精簡模式挑高價值類型，跳過大量日常病程。
逐筆點開等待右側 iframe 載入。
讀取#nav-tabContent
輸出過去病史、門診用藥、近期手術紀錄。

目前輸出重點

1. 過去病史

從入院病摘、出院病摘、轉入/轉出病摘與急診內容抓診斷、既往病史與慢性病線索。

2. 門診用藥

從讀到的文字中找用藥、藥物、medication、口服、qd/bid/tid 等線索。

3. 近期手術紀錄

從病摘中找手術、術後、operation、procedure、清創、引流、導管等線索。
